Detailed Description

A flecs system, modelled exactly like flecs::system.

Mirrors flecs::system final : flecs::entity: a System IS the system entity. It is non-template and stores no extra members — the inherited Entity identity (world + flecs entity) is the system. System-specific methods reconstruct a flecs::system on demand from that entity, exactly as flecs::world::system(e) adopts an existing entity (it does NOT create a new system).
