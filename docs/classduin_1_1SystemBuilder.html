Detailed Description

template<typename... Components>
class duin::SystemBuilder< Components >

Wrapper for flecs::system_builder to provide a unified system builder API.

Mirrors QueryBuilder. Unlike QueryBuilder there is no Build(): the terminal methods Each()/Run() register the callback and return the constructed System.

IMPORTANT: flecs::system_builder (via node_builder) defines NO copy/move constructor, so its internal desc_/term_ pointers reference its own storage by raw address. Moving or copying it leaves those pointers dangling at the source object, and any term added afterwards (With/Without/Each) writes into freed memory. (flecs::query_builder is safe because its base DOES re-point on move/copy.) We therefore heap-hold the flecs builder in a unique_ptr and never move it after construction, keeping its internal pointers valid for the whole lifetime of the chain.
