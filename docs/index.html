Duin Engine

Introduction

Duin is a C++20 game engine built on an Entity Component System (ECS) architecture. It combines FLECS for data-oriented entity management with a traditional GameObject hierarchy for scene organization.

Features

  • FLECS ECS - Entity/component data storage and system queries
  • PhysX Physics - NVIDIA PhysX for rigid body dynamics and collision
  • BGFX Rendering - Cross-platform graphics (D3D11/12, OpenGL, Vulkan, Metal)
  • SDL3 - Window management and input handling
  • ImGui - Immediate mode GUI for tools and debugging

Architecture Overview

The engine combines two organizational patterns:

ECS (Data-Oriented)

Entities are identifiers with attached components (pure data). Systems query entities by component patterns and process them efficiently.

// Create entity with components
flecs::entity e = world.GetFlecsWorld().entity()
.set<ECSComponent::Position3D>({0, 0, 0})
.set<ECSComponent::Rotation3D>({})
.add<ECSTag::PxDynamic>();

GameObject (Object-Oriented)

GameObjects form parent-child hierarchies with lifecycle callbacks (Init, Ready, Update, Draw). Useful for logical organization and behavior.

class Player : public duin::GameObject {
void Update(double delta) override {
// Per-frame logic
}
};

Modules

  • Core Module - Application lifecycle, events, signals, math, utilities
  • Entity Component System - Entity Component System (FLECS wrapper)
  • Physics Module - PhysX integration
  • Render Module - BGFX rendering
  • Objects Module - GameObject hierarchy and state machine
  • Input/Output Module - File I/O, JSON, configuration
  • Assets Module - Asset management

Building

Duin uses Premake5 for project generation.

Generate Project Files

# Windows (Visual Studio 2022)
vendor\bin\premake\premake5.exe vs2022
# Linux/macOS
vendor/bin/premake/premake5 gmake2

Build

# MSBuild (Windows)
msbuild Duin.sln -property:Configuration=Debug -property:Platform=x64
# Or open Duin.sln in Visual Studio 2022

Dependencies (First Time)

vendor\bin\premake\premake5.exe --deps vs2022

Coordinate System

Right-hand rule with +Z toward the viewer (same convention as Godot).
